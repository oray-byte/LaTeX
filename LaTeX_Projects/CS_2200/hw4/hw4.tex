	\section{}
	A Context Free Grammar is made up of three parts:
	\begin{enumerate}
		\item A finite set called \textbf{variables}
		\item A finite set, disjoint from set of \textit{variables}, called \textbf{terminals}
		\item A finite set of \textbf{rules} with each being a variable going to string of \textit{variables} and \textit{terminals}
	\end{enumerate}
	Note: A Context Free Grammar also is made up \textit{starting variable} but does not always need to be defined. If the \textit{starting variable} is not defined, the variable in the first rule is assumed to be the \textit{starting variable}
